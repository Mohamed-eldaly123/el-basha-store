# موقع مركز المهندس للإلكترونيات وصيانة الشاشات

موقع إلكتروني متكامل ومتجاوب لمركز المهندس للإلكترونيات (إدارة م. محمد التهامي).

## 📂 محتويات المجلد:
- `index.html`: الصفحة الرئيسية للموقع وتتضمن الهيكل والربط مع قاعدة البيانات واللغتين العربية والإنجليزية.
- `style.css`: ملف التنسيقات والألوان والأشكال السايبرانية والتحريكات.
- `التقاط.PNG`: شعار المركز الأصلي المدمج بالهيدر.

## 🚀 كيفية التشغيل:
1. تأكد من وجود ملف `التقاط.PNG` في نفس مجلد ملف `index.html`.
2. اضغط مرتين على ملف `index.html` لفتحه في أي متصفح (Chrome, Edge, Firefox).
